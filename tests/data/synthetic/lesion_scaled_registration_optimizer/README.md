# Scaled LesionTOADS optimizer-loop fixture

`java_reference.json` is generated by
`tests/java_reference/LesionScaledRegistrationOptimizerReferenceHarness.java`
using `scripts/generate_java_lesion_scaled_registration_optimizer_reference.sh`.
It transcribes the selected scaled coefficient and line-search formulas over
deterministic 8³ two-class prior and membership arrays, then follows the
`registerShapesPyramid` per-scale loop condition.

The fixture contains three controls: normal source stops after the lambda
floor is crossed, an explicit three-iteration limit, and a larger minimum
relative energy-change threshold. Every outer iteration stores each trial
transform/energy and the accepted update fields. This verifies loop order,
lambda carry-over, and all three stop criteria without advancing pyramid
levels.

This is a fixed-scale formula excerpt, not a complete atlas registration or
LesionTOADS run. It does not validate scale construction/transitions,
transformed-bound optimization, deformable registration, or segmentation.
