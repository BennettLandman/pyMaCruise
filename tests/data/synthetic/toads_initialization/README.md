# TOADS initial-membership phantom

This tiny deterministic numeric phantom exercises source-derived initial
centroids and exact memberships before atlas alignment. It has two channels,
four classes, and a duplicated first-channel centroid pair so the source's
class-group multiplicity rule is observable. The center voxel matches one
class centroid exactly and exercises the `1e20f` reciprocal cap. `spec.json`
records dimensions, bounds, priors, and the image recipe; the test constructs
the arrays directly so no derived non-NIfTI image is stored.

The expected result was generated by the standalone Java copy of
`MultipleToadPreprocess.initialCentroids` and
`initialExactMemberships`; it is not a full TOADS implementation reference.
Regenerate it with:

```sh
javac -d /tmp/pymacruise-toads-init tests/java_reference/ToadsInitializationReferenceHarness.java
java -cp /tmp/pymacruise-toads-init ToadsInitializationReferenceHarness \
  > tests/data/synthetic/toads_initialization/java_reference.json
```

The selected `AlgorithmMultipleToads` constructor sets `useApprox=false`, so
this is the active initialization branch for the selected wrapper. The source
uses float32 arithmetic and exact equality on channel-0 centroids; those
behaviors are retained. Atlas-prior parsing, atlas registration, and iterative
segmentation are not covered by this fixture.
