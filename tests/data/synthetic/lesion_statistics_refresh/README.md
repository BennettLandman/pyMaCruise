# LesionTOADS statistics-refresh phantom

`statistics_refresh_inputs.nii.gz` is generated by `generate_fixture.py` as a
6 × 5 × 4, 13-frame synthetic RAS NIfTI with nonlinear folded label boundaries. Frames contain hard labels, five
membership maps, two channels, two fixed correction fields, and outlier,
lesion, and black-hole maps. It contains generic OBJECT, OPTIMIZED_GM, LESION,
and BLACKHOLE classes; class 4 is intentionally absent. Explicit voxels force
LESION and BLACKHOLE membership winners and a lesion/black-hole tie.

`LesionStatisticsRefreshReferenceHarness.java` is a standalone Java excerpt
harness for the selected `LesionToadSegmentation.computeCentroids()`,
`computeVariances()`, and `computeChannelWeights()` bodies composed in the
selected `AlgorithmLesionToads.runAlgorithm()` order. It uses the preserved
upstream `PowerTable.java` for optimized-GM and lesion-centroid terms. The
selected `LesionToadSegmentation.java` SHA-256 is
`545a61027d22efcc5d07d6bea960039c938808867707cbbd61811cad46cc3a99`.
The selected wrapper `AlgorithmLesionToads.java` SHA-256 is
`556940249cb3a8191f53f23a76308f11823789f7b41f7a83b071d784ae4a20cb`.
The preserved `PowerTable.java` SHA-256 is
`2c75d78ff33efd11531a3227399acc6fb2a421e2b4205ad6c77e6533eadd50ae`.
Run `scripts/generate_java_lesion_statistics_refresh_reference.sh` to rebuild
the raw-float-bit `java_reference.json`.

This fixture validates one fixed-input statistics refresh and its call order;
it does not estimate correction fields, perform thinning, or validate a full
LesionTOADS iteration.
