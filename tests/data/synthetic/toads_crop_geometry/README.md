# Synthetic TOADS crop geometry reference

This fixture records selected geometry behavior from the selected `toads-cruise` source. It covers inclusive crop bounds, zero-padded crop dimensions, the transform translation update and inverse update, and nearest-neighbor transformation of a categorical topology.

## Provenance and execution status

`java_reference.json` was generated by `tests/java_reference/ToadsCropGeometryReferenceHarness.java` using the command below. The harness now carries source-excerpt copies of the selected `MultipleToadPreprocess` method bodies, and executes those bodies over this committed asymmetric fixture. This is a selected-method Java comparison, **not** execution of the complete upstream `MultipleToadPreprocess` class.

The method excerpts added for the crop-bound comparison are:

- `MultipleToadPreprocess.findCroppingBoundaries()` (source lines 302–345: image threshold support plus transformed topology support; inclusive endpoints)
- `MultipleToadPreprocess.computeImageCoordinates()` (source lines 653–660)

The existing fixture also checks supporting behavior represented by test-only formula transcriptions: `cropImages()`/`uncropImages()` (padding, voxel copy, clipping, center changes, and translation updates), `computeTemplateCoordinates()`, `generateTransformedTopology()`'s sampling loop, `RotationMatrix.setParameters(float,float,float)`, `ImageFunctions.nearestNeighborInterpolation(...)`, and `Numerics.floor(float)`, `ceil(float)`, and `round(float)`.

The surrounding upstream class cannot be compiled from the supplied checkout by itself. A direct `javac` attempt on `MultipleToadPreprocess.java` fails because the checkout does not include required MIPAV/JIST dependencies, including `gov.nih.mipav.model.file.FileInfoBase`, `gov.nih.mipav.view`, `MultipleToadDeformableAtlas`, and referenced library/utility classes (80 compiler errors). The harness therefore uses only the relevant method excerpts and small supporting formula excerpts; it avoids fabricating stubs for the absent application framework.

## Phantom specification

- Image dimensions: `7 x 8 x 6`, indexed `[x][y][z]`; template dimensions: `7 x 8 x 6`.
- Image voxel resolutions: `[1.0, 1.25, 1.5]`; template resolutions: `[1.0, 1.0, 1.0]`.
- Image orientation signs: `[-1, -1, +1]`, the selected RAS convention from `MultipleToadPreprocess` (L2R, P2A, I2S axis codes). Positive anisotropic image resolutions `[1.0, 1.25, 1.5]` exercise the source sign handling while preserving voxel spacing magnitudes.
- Fixed Rodrigues vector: `[0.12, -0.08, 0.05]`; initial translation: `[0.4, -0.25, 0.3]`.
- Source image values are zero outside `x=1..5, y=2..6, z=1..4`. Inside, a deterministic modular pattern sets values in tenths; positions where `(x + 2*y + 3*z) % 5 == 0` remain zero. The source normalized-image threshold is `0.2`.
- Topology background label is `1`. A hollow `3 x 3 x 3` shell is label `2`; a solid `4 x 4 x 4` block at `x=3..6, y=3..6, z=2..5` is label `3` (overwriting part of the shell to ensure this second class reaches the resampled output).
- Border size is `2`. This puts the source image support against the x boundary and exercises crop padding and clipped uncropping.

## Generate the JSON

From the repository root:

```sh
mkdir -p /tmp/pymacruise-crop-classes
javac -d /tmp/pymacruise-crop-classes tests/java_reference/ToadsCropGeometryReferenceHarness.java
java -cp /tmp/pymacruise-crop-classes ToadsCropGeometryReferenceHarness > tests/data/synthetic/toads_crop_geometry/java_reference.json
```

The recorded inclusive bounds are `[0,7,1,6,1,5]`; after a two-voxel border the crop is `[12,10,9]`. The JSON contains the complete cropped image, transformed topology, uncropped image, and transforms before/after the crop round trip. Float values are serialized to nine significant digits from Java floats.

## Python validation

`tests/test_toads_crop.py` compares all six inclusive bounds and transformed topology labels exactly, plus the complete crop/uncrop arrays and translations, against this fixture. This is one RAS synthetic case with nonzero rotation and translation, a boundary-touching image, and two nonbackground topology labels. Identity-transform, broader orientation, and other boundary-specific Java comparisons remain separate coverage needs; this case does not establish general crop parity or full TOADS equivalence.
