# LesionTOADS coarse-to-fine registration fixture

`java_reference.json` is generated by
`tests/java_reference/LesionRegistrationPyramidReferenceHarness.java` and
`scripts/generate_java_lesion_registration_pyramid_reference.sh`. The harness
uses selected `ImageFunctions.subsample`, `ParametricTransform`, and
`ImageFunctions` interpolation/derivative methods, followed by the selected
LesionToadAtlas scaled coefficient, energy, and line-search formulas.

The synthetic 33³ two-class membership and atlas fields have odd dimensions
and deterministic patterned values. The fixture covers levels 1 through 4:
level 1 has no optimization stage; level 4 visits scales 8, 4, and 2. It
records coarse dimensions, transform handoff, lambda reset through each stage,
all trial transforms/energies, and final transforms. A JSON `null` in an
energy trace denotes Java's IEEE NaN from a trial with zero prior norm; the
source strict-increase test rejects that trial and continues backtracking.

This is selected-formula pyramid-registration evidence only, not a full
`LesionToadAtlas` run, lesion segmentation, or plus-workflow equivalence.
