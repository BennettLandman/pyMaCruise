# Initial default-atlas membership after field attachment

This composition connects the selected `AlgorithmMultipleToads` startup call to the existing fixed-state exact-membership implementation. The selected default descriptor has 11 classes in order: MASK, two OPTIMIZED_CSF, five OPTIMIZED_GM, and three OPTIMIZED_WM. The wrapper attaches one fitted field reference per channel, computes relations, boundary distances, closest labels, and variances, then calls `computeMemberships`; its selected `MedicAlgorithmToads08` constructor forces `useApprox=false`, so the first membership call dispatches to `computeExactMemberships`.

The Python composition implements the field attachment and calls the existing Java-matched `toads_default_atlas_membership_pass`. It consumes upstream statistics, relation labels, transformed shapes, and modality weights as fixed inputs; it does not implement their estimation or the complete startup workflow. Numerical expected outputs reuse the `field=true, psf=true, smoothing=true, prior=true` case from `toads_default_atlas_dispatch`, whose harness compares the selected 11-class membership method.

The small RAS NIfTI input volumes are reused from `tests/data/synthetic/toads_default_atlas_dispatch/`. The Java order harness validates the per-channel attachment state and wrapper call order.
