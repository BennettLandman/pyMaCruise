# LesionTOADS rigid transformed atlas template

This synthetic 9 x 10 x 11 integer-label atlas is stored as compressed NIfTI
on a positive-direction RAS grid with voxel sizes 0.9 x 1.0 x 1.1 mm. The
Java harness creates the same label pattern in memory and applies the
selected rigid atlas-to-image mapping on a 7 x 8 x 9 image grid. The JSON
reference is generated by running
`tests/java_reference/LesionToadAtlasTransformedTemplateReferenceHarness.java`.
Voxel `[0,0,0]` is deliberately set to label 42 while atlas metadata
`label[0]` is 1, proving out-of-bounds fill comes from class metadata rather
than copying the atlas corner.

The fixture isolates categorical nearest-neighbor map construction, including
the source's out-of-grid background label and selected rotation/translation.
It does not exercise multi-transform averaging or any non-rigid transform.
