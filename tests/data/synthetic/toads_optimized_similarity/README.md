# Optimized TOADS centroid-similarity fixture

This small numerical fixture composes the no-field outputs of the P18am
image-variance and P18an class-standard-deviation Java formula harnesses with
the initialized CSF/GM/WM centroids. It uses three modalities and three
optimized tissue classes. The selected TOADS source default
`priorScale=0.05f` is used.

`java_reference.json` records the class-pair similarity matrix from the
selected `computeExactMemberships` source formula excerpt and includes the
source file hash. It is regenerated by
`scripts/generate_java_toads_optimized_similarity_reference.sh`. Zero
diagonal entries and source IEEE behavior for zero deviation denominators
are tested separately. This fixture does not include voxelwise priors or
membership evolution.
