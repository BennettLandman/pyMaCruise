The crop bounds are `[-1,1,1,2,-1,0]`, padding is one voxel, and the original
image is `[4,5,3]`. This clips the low side of x and z support while leaving
high-side background voxels in the restored extent. Scalar floats use a
nonzero `-7.5` background, labels use byte background `9` and values spanning
the signed-byte range, and two float channels use background `2.25` with
distinct values. The expected packed arrays are stored as flattened Java
buffers: x is fastest within a volume, and multi-channel data is channel-major.

`tests/test_toads_uncrop_buffer.py` compares Python's flattened arrays exactly
against these Java-generated values and pins both harness and fixture hashes.
This validates output-buffer assembly only. It does not validate NIfTI header
or serialization behavior, MIPAV image import, or end-to-end TOADS outputs.
