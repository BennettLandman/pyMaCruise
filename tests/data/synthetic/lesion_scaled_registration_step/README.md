# Scaled LesionTOADS registration-step fixture

`java_reference.json` is generated by
`tests/java_reference/LesionScaledRegistrationStepReferenceHarness.java`
using `scripts/generate_java_lesion_scaled_registration_step_reference.sh`.
It applies the selected scaled LesionToadAtlas coefficient formulas and
strict-energy-increase line search to deterministic, predeclared synthetic
shape maps and membership fields.

The scale-1 case accepts its first trial. The scale-2 case starts with a larger
step, rejects eight trials, then accepts the ninth. The fixture records each
candidate transform and energy as well as the final transform, energy, lambda,
relative change, acceptance flag, and rejected-trial count. This validates one
scaled registration update at two pyramid levels and exercises both immediate
acceptance and lambda backtracking.

This is a selected-method formula excerpt, not a full `LesionToadAtlas` run.
It does not validate repeated outer iterations, convergence/stopping criteria
across iterations, deformable registration, or lesion segmentation.
