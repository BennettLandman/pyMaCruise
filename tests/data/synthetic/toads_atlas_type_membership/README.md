# P18czk synthetic TOADS atlas-type membership fixture

This fixture exercises the selected VandyCRUISE exact-membership branch for
the bundled TOADS2012 13-structure atlas descriptor. The descriptor is named
`cruise-atlas-12obj-toads2012.txt` but declares `Structures: 13`: one MASK,
two OPTIMIZED_CSF classes, and ten OBJECT classes, in descriptor order.

The subject images, fields, PSF bias, memberships, transformed priors, closest
labels, and folded ribbon use a 9×8×7 true-RAS voxel grid at 0.9×1.2×1.45 mm.
`atlas_template_shapes.nii.gz` uses a distinct 11×10×9 true-RAS grid at the
same spacing, with its [1,1,1] voxel sharing the RAS point of subject voxel
[0,0,0]. The membership adapter receives transformed priors already sampled
on the subject grid; template sampling and registration remain outside this
fixed-input slice.

`java_reference.json` was generated by
`scripts/generate_java_toads_atlas_type_membership_reference.sh`, which checks
the source and descriptor hashes before compiling the selected `PowerTable`
and running `ToadsAtlasTypeMembershipReferenceHarness.java`. Reference cases
cover all combinations of field, PSF, smoothing, and prior enabled/disabled.
The selected source hashes are:

- `MultipleToadSegmentation.java`: `63e135f36dd9117a4f6dda2ec78990230e5e44ad91234ce3745d20e5976cd884`
- `MultipleToadAtlas.java`: `914839a0885cb26ff3ac22daeeb2603ee1960368b788da3ad343a54053f031db`
- `PowerTable.java`: `5552069bec24dad8e50d426c77babfb041f952166a8c786091ade22eec8ec678`
- `cruise-atlas-12obj-toads2012.txt`: `096eb94f9c814f47535e308b8b0d63eaacbbfc646efc1dd06c8ecd8f0892f006`

The fixture is synthetic and uses no patient data. Rebuild the NIfTI inputs
with `scripts/generate_toads_atlas_type_fixture.py`; regenerate the Java
reference with the shell script above. The focused comparison is
`pytest -q tests/test_toads_atlas_type_membership.py`.

The comparison covers the 13 per-class data-energy and membership maps,
denominator, and objective float32 bits; parser order and unknown-topology
fallback; shared CSF category exponents with distinct class statistics;
direct/neighbor/prior paths; input immutability; and unchanged six-face
membership borders. It validates this fixed-statistics membership slice, not
atlas loading, transformed-prior generation, statistics estimation,
approximate memberships, registration, or full TOADS workflow behavior.
