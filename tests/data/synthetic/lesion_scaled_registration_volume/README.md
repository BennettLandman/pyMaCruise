# Scaled LesionTOADS registration volume fixture

`java_reference.json` is generated by
`tests/java_reference/LesionScaledRegistrationVolumeReferenceHarness.java`
using `scripts/generate_java_lesion_scaled_registration_volume_reference.sh`.
The harness uses the selected upstream `ParametricTransform`,
`RotationMatrix`, and `ImageFunctions` implementations to map and sample every
selected coarse input voxel, then applies the `LesionToadAtlas` scaled
registration coefficient formulas in x/y/z/class order.

Two synthetic cases use pyramid scales 2 and 4, odd full-resolution image
dimensions, anisotropic voxel resolutions, a nonzero rigid transform, four
classes, and offset-zero step-two sampling. Shape maps have deterministic
class-dependent affine/bilinear patterns; class 0 is nonzero but excluded by
the registration loop. The records include raw and normalized cost, norm,
gradient, diagonal Hessian, and sample/contribution counts. Small coarse grids
exercise fractional transformed coordinates and zero-default samples outside
the template.

This is selected-formula fixed-transform validation, not a full
`LesionToadAtlas` run. It does not validate pyramid construction, line search,
transform updates, optimized bounds, or lesion segmentation.
