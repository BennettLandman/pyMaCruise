# LesionTOADS single-voxel registration fixture

This synthetic formula case uses a 6×6×6 grid, an identity rigid transform,
and its center voxel `(3, 3, 3)`. Four maps represent: class 0 with nonzero
values (which the registration loop excludes), two positive affine-valued
shape priors, and one all-zero class. Memberships are `[0.9, 0.5, 0.75,
0.6]`. With the voxel at the image/template center, the selected rigid
coordinate Jacobian has zero rotation columns and unit translation columns.

The reference is generated by the small Java source-formula excerpt
`tests/java_reference/LesionRegistrationVoxelReferenceHarness.java` (SHA-256
recorded by `tests/test_lesion_shapes.py`). It follows the selected
`LesionToadAtlas.computeRegistrationCoefficients` class and positive-prior
gates and coefficient expressions, but does not compile or instantiate the
complete atlas class. The shape-sampling, prior-derivative, coordinate
Jacobian, and coefficient-accumulation components also have their own
source-comparison fixtures.

Regenerate with `scripts/generate_java_lesion_registration_voxel_reference.sh`
from the repository root using a JDK. No image files or clinical data are
used in this reference.
