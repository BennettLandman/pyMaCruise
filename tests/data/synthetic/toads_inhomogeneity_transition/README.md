# TOADS inhomogeneity degree-transition fixture

This synthetic 18×18×18 fixture has two distinct image channels, four approximate-class slots, an asymmetric folded correction mask, and a true-RAS affine with voxel sizes 0.85, 1.15, and 1.55 mm. Its 11-class channel-specific centroid rows, memberships, best candidates, segmentation, and initially unit-valued attached fields are committed beside this note.

The pinned Java reference selects degree 2 from degree 1 when the previous energy ratio (0.4) is strictly below `lowEratio` (0.5), then selects degree 3 from degree 2 on the next below-threshold update. Equality, above-threshold, and degree-cap cases produce the reference degree sequence `[3, 2, 2, 3]` for the separate boundary checks. Per update, channel 0 is fit before channel 1, and all channel fits for a degree finish before the following degree update begins.

The harness records exact normal-system and RHS bits for each channel/degree. On this two-channel transition fixture, the measured maximum NumPy/Jama coefficient differences are **3.3306690738754696e-13** at degree 2 and **1.4509726753431096e-11** at degree 3. For this fixture, the mean-centered float32 fields match the Java reference exactly by SHA-256 for both channels after both updates and after the final update. Outside the segmentation correction mask, the field remains exactly one. Java and Python confirm selected downstream channel samples use `field * raw_image`; the input images are unchanged.

The Java harness is `tests/java_reference/ToadsInhomogeneityTransitionReferenceHarness.java`; regenerate `java_reference.json` with `sh tests/java_reference/generate_toads_inhomogeneity_transition_reference.sh`. The harness pins the selected TOADS loop, field setter, polynomial fitter, Jama solver, and PowerTable source hashes. It independently executes only the source-ordered ratio/degree decision and two-channel degree-2 then degree-3 field fits. It does not execute thinning, centroid/statistics updates, memberships, growing, or a complete TOADS iteration.
