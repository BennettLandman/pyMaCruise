# P18czn synthetic approximate-registration reference

The numerical inputs reuse the P18czl fixture:

- `../toads_lesion_atlas_type_membership/images.nii.gz`: asymmetric 9×8×7,
  two-channel, true-RAS synthetic subject intensities.
- `../toads_lesion_atlas_type_membership/transformed_shapes.nii.gz`: thirteen
  current-transform atlas priors on the subject grid, including folded
  cortex-like structure.
- `../toads_lesion_atlas_type_membership/atlas_template_shapes.nii.gz`:
  thirteen template-space priors on a distinct 11×10×9 true-RAS grid.

The fixture uses `approx=3`, three pyramid levels (scale 4 then 2), a rigid
preprocessing transform, and the selected two-voxel registration scan. Java
reference output in `java_reference.json` is generated by
`tests/java_reference/generate_toads_lesion_approximate_registration_reference.sh`.
The harness reads only repository-local fixture/descriptor files and compiles
against copied `ParametricTransform`, `RotationMatrix`, `ImageFunctions`, and
`Numerics` sources under `tests/java_reference/upstream`; it does not require
the supplied source checkout at test time.

The reference captures top-k initialization arrays, candidate slots after
each coarse pooling pass, per-iteration normalized gradient/Hessian, every
line-search trial, energy/lambda/stop state, and transform handoff. It also
records source SHA-256 identifiers and wrapper call order. The approximation
is specifically the optional registration initialization path. The selected
iterative segmentation constructor sets `approx=0`, so these results do not
claim approximate later membership evolution or full TOADS segmentation.
