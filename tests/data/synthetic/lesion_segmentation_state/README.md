# LesionTOADS segmentation-state initialization fixture

This compact synthetic RAS fixture isolates deterministic constructor-time
state from the selected VandyCRUISE `LesionToadSegmentation` implementation.
It is not a patient image and it does not represent lesion-segmentation
performance.

The `3×2×2` grid contains two nonconstant float32 channels (`t1.nii.gz` and
`flair.nii.gz`) and a template label image (`template_labels.nii.gz`). Labels
1 and 2 occur four and eight times respectively; atlas class 3 is absent to
exercise the Java constructor's `0/0` NaN centroid. The class types are
`obj`, `lesion`, and `optimized_blackHole`, which checks that the constructor
selects the explicit lesion class while leaving the optimized black-hole
class separate. Affines are identity RAS matrices with millimetre units.

`java_reference.json` is generated by the standalone selected-constructor
formula excerpt in `tests/java_reference/LesionSegmentationStateReferenceHarness.java`.
Regenerate it with
`scripts/generate_java_lesion_segmentation_state_reference.sh`. The harness
captures label-to-index mapping, source-order float32 volume/centroid
accumulation, zero membership/availability, class and lesion similarity
defaults, and distance sentinels. It does not instantiate the entire source
class or validate topology propagation and segmentation evolution.
