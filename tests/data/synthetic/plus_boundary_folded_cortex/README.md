# Folded plus boundary fixture

`segmentation.nii.gz` is a deterministic 66×76×66 RAS label phantom with a
folded cortical shell, two adjacent cortical labels (100 and 101), an inner
label (110), low-valued label-4 contact, and label 120 from the selected
overlook list. It is generated by
[`generate_plus_boundary_folded_fixture.py`](../../../../scripts/generate_plus_boundary_folded_fixture.py).
The fixture exercises positive inter-cortical boundary voxels, suppression at
low-valued contact, overlooked-label removal, and interior-only volume edges.
It contains no subject imaging data.

The saved plus workflow crop is retained as a second held-fixed comparison
input. That case has an empty raw-boundary output because its only cortical
label is 100 and every candidate touches a suppressed low-valued label; it is
reported separately and is not treated as sufficient boundary evidence.
