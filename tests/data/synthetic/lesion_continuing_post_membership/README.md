# P39zzzzw continuing post-membership fixture

This row reuses the committed folded, asymmetric, multi-channel RAS volume
[`iteration_inputs_ras.nii.gz`](../lesion_continuing_iteration/iteration_inputs_ras.nii.gz)
from P39zzzzv. The image is synthetic and self-contained; tests do not open the
VandyCRUISE checkout. It supplies the T1/T2 images, correction fields, class
labels and memberships, shape maps, lesion/black-hole/outlier maps, and the
segmentation/thinning state used to produce an actual P39v result.

`java_reference.json` is generated by
[`LesionContinuingPostMembershipReferenceHarness.java`](../../../java_reference/LesionContinuingPostMembershipReferenceHarness.java).
The excerpt pins selected wrapper order and float32 energy-ratio, convergence,
iteration-limit, signed-growth, and stop-versus-relation-refresh decisions.
Registration and the selected grow/classification/relation methods have
separate Java-reference fixtures; this row composes those validated kernels
after the real P39v state.
