# P18cyn selected TOADS startup-to-thinning fixture

This committed deterministic synthetic case exercises a bounded source-order
composition: attach two correction fields, compute relation/boundary/closest
label state from fixed initial segmentation and memberships, run the selected
11-class exact-membership update with fixed upstream statistics and atlas
shape samples, then feed those memberships and relation adjacency into the
first thinning pass.

The RAS NIfTIs contain a 25×25×25 folded 11-class label field, normalized
starting memberships, two synthetic intensity channels, two nonunit fitted
fields, PSF-bias values, and nonzero spatially folded transformed-shape samples.
All volumes share the same RAS+ millimetre affine. They are generated by
[`generate_fixture.py`](generate_fixture.py); regenerate with:

```sh
.venv/bin/python tests/data/synthetic/toads_initial_thinning_startup/generate_fixture.py
scripts/generate_java_toads_initial_thinning_startup_reference.sh
```

`spec.json` records the fixed centroids, variance/image-variance weights,
centroid similarities, modality weights, shape priors, source parameters, and
the starting state. These are explicit upstream inputs; this fixture does not
estimate them, perform registration, or claim T1-driven atlas initialization.
The 100-voxel thinning floor is active for several classes, and the reference
records over 11,000 queue events with source volume reductions.

`java_reference.json` is generated by
[`ToadsInitialThinningStartupReferenceHarness.java`](../../../java_reference/ToadsInitialThinningStartupReferenceHarness.java).
The harness executes selected Java method excerpts for the relation refresh,
then the selected exact-membership formulas, followed by the VandyCRUISE heap,
volume, shape-prior, and topology-gated thinning logic. It records digests for
each intermediate/final array and the ordered queue trace. Selected source,
PowerTable, 18/6 LUT, and heap hashes are in the JSON; dependent Java excerpt
hashes are pinned by the test.

This validates only the selected startup slice through one initial thinning
pass. Class and image statistics, transformed atlas samples, and transforms
are fixed. It is not a complete TOADS workflow or a T1-driven run.

## Post-thinning continuation slice

`tests/test_toads_initial_thinning_statistics_membership.py` reuses the
same 25-cubed folded RAS fixture and the Java-pinned startup/thinning outputs,
then composes the selected exact-centroid refresh, assigned-class variance
refresh, centroid-similarity calculation, and next 11-class exact-membership
pass. This composition uses the thinned segmentation and startup membership
map; the image variance and other non-refreshed statistics remain fixed. It
checks the consumed startup membership and thinned labels against the direct
P18cyn Java reference. The post-thinning combination itself does not yet have a
single independent Java end-to-end digest; the centroid, variance, similarity,
and membership kernels have separate source-harness validation elsewhere.
This is a bounded selected continuation, not complete TOADS equivalence.
