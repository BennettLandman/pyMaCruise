# LesionTOADS initial membership fixture

`padded_multichannel_ras.nii.gz` is a deterministic, asymmetric 7×8×9
two-channel synthetic image with an explicit RAS affine. Its active crop has
source-coordinate bounds `[(2, 7), (3, 9), (4, 11)]` and one zero-valued pad
voxel on each face. `inputs.json` records the matching centroids and float
bits. The first active voxel has exactly zero squared distance to one class;
two classes share the first-channel centroid so the source grouping rule is
observable. The other classes have distinct centroids. `java_reference.json`
contains the selected-method harness's complete output membership float bits,
including zero-valued padded output.

The synthetic image is generated by `generate_fixture.py`. No clinical data or
external source checkout is required by the test. Java provenance is pinned in
`tests/java_reference/LesionInitialMembershipsReferenceHarness.java` to
VandyCRUISE `LesionToadPreprocess.java`, SHA-256
`72a1a47dae9c448022707ee68917eb5ca70d64b763f38582fa31304463732c08`.
The Java harness is a focused excerpt of `initialMemberships()`, not a complete
preprocessing or registration reference.
