# TOADS exact polynomial field degrees 2 and 3

A deterministic 21³ synthetic RAS phantom with an angularly folded cortical shell, a smooth positive intensity field, eleven soft class-membership maps, and an initial unity correction field. All images are stored as `.nii.gz`. The fixture provides enough stride-three samples to identify the 10-term degree-2 and 20-term degree-3 Chebyshev models. Regenerate with `python generate_fixture.py`.
