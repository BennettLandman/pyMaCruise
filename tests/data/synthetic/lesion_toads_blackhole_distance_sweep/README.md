# LesionTOADS BLACKHOLE distance sweep fixture

This committed `5×4×6` selected-Java formula reference covers the asymmetric
BLACKHOLE distance path. Coordinate-dependent signed-byte ventricle, GM, and
brainstem maps exercise ventricle precedence (lesion map changes while the
black-hole map is not distance-scaled), GM fallback with the flag enabled or
disabled (both maps scale), zero-distance spread, and independent brainstem
scaling. The fixture includes direct/prior relations and one zero-shape
BLACKHOLE voxel. Every interior class, lesion, and black-hole membership is
stored as a float32 bit pattern.

Regenerate with
`scripts/generate_java_lesion_toads_blackhole_distance_sweep_reference.sh`.
This validates the selected BLACKHOLE distance branch only, not the full
LesionTOADS segmentation.
