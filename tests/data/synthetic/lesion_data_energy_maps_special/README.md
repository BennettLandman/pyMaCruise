# P39zzzzn fielded and special LesionTOADS energy fixture

`inputs_ras.nii.gz` is a deterministic 7×8×9×6 synthetic RAS image. Its first
three channels contain folded, asymmetric intensity patterns; its final three
channels contain non-unit intensity fields. Spacing is 1.5×2.0×2.5 mm. The
fixture is generated by `scripts/generate_lesion_data_energy_maps_special_fixture.py`.

`java_reference.json` was generated by
`scripts/generate_java_lesion_data_energy_maps_special_reference.sh` and the
pinned upstream `PowerTable.java`. The Java harness is
`tests/java_reference/LesionDataEnergyMapsSpecialReferenceHarness.java`. It
captures selected `LesionToadSegmentation.computeMemberships()` raw data
energy branches for OBJECT/Sulcal-CSF, LESION, and BLACKHOLE classes. Cases
cover field on/off, exact and case-mismatched Sulcal-CSF names, T1 absent,
MPRAGE PowerTable enabled/disabled, and LESION FLAIR weighting with/without a
field. The selected method and wrapper hashes are recorded in the JSON.

This fixture validates data-term map construction only. It does not execute
centroid/statistic estimation, optimized tissue branches, topology/relation
skips, smoothing, atlas priors, inversion, map normalization, or iteration.
LESION and BLACKHOLE energy slots retain source class-order overwrite
behavior, and all output maps remain zero on the untouched one-voxel faces.
