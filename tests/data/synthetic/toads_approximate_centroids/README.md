# Selected default TOADS approximate-centroid fixture

This synthetic 18×18×18 two-channel fixture uses a folded mask, anisotropic true-RAS geometry (0.85, 1.15, and 1.55 mm), four candidate membership slots, and the selected 11-class descriptor order: MASK, optimized CSF×2, optimized GM×5, optimized WM×3. Its per-channel field is the final degree-3 field from the P18cyb sequence and matches both Java-reference field hashes exactly. The channel-specific powers are T1 MPRAGE (0.8, 1.0, 1.0) and FLAIR (1.0, 1.0, 1.0), as specified by the bundled descriptor.

`ToadsDefaultApproximateCentroidReferenceHarness.java` executes the selected full-grid channel/x/y/z/candidate-slot accumulation and damped centroid formula using the checked-in `PowerTable` Java source. The reference records all per-channel/class numerator, denominator, and updated-centroid float32 bits. The fixture includes repeated candidate labels, nonunit channel-specific fields, boundary candidates, and optimized-class distances both at/below the source ZERO threshold and above it for PowerTable lookup. A separate reference pass suppresses class 10's candidate weights to test zero-support centroid retention.

Regenerate `java_reference.json` with `sh tests/java_reference/generate_toads_default_approximate_centroid_reference.sh`. The JSON pins selected `MultipleToadSegmentation`, `AlgorithmMultipleToads`, `MedicAlgorithmToads08`, the VandyCRUISE `PowerTable`, and atlas-descriptor source hashes. The Java reference is for this approximate centroid update only; it does not perform variance updates, membership updates, or a TOADS iteration.
