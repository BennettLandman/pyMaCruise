# Downsampled bundled VandyCRUISE atlas synthetic phantom

This deterministic, coarse whole-brain phantom is generated from the atlas maps already bundled in this repository. Its 36×45×34 grid preserves the source field of view and atlas labels; a synthetic T1 is synthesized from the descriptor's T1_MPRAGE class proportions with a small smooth bias. All stored images are compressed NIfTI in RAS orientation. Regenerate with `python generate_fixture.py`.

This is not clinical data and does not establish full MaCRUISE-workflow equivalence or clinical performance. The selected VandyCRUISE loop now has committed source references through natural convergence at iteration 19; `nineteen_iteration_java_reference.json` records membership hashes and all 19 post-registration transforms, and `nineteen_iteration_java_classification.nii.gz` stores the final Java labels in RAS. The earlier 12-cycle reference retains complete membership arrays for direct per-value comparisons. The coarse spacing is intended to make a folded whole-brain convergence/runtime experiment practical.
