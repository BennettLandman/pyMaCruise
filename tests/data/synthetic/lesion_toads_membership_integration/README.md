# LesionTOADS membership-integration reference

This synthetic selected-Java formula fixture composes class energy inversion,
direct/prior relation scaling, lesion and black-hole distance modulation,
denominator accumulation, and final one-voxel normalization. The five cases
cover direct and prior lesion updates, the black-hole ventricle source
asymmetry, GM and brainstem distance factors, mixed class types, and a
zero-denominator prior case.

Inputs are precomputed class, lesion, and black-hole energies; this is a
selected formula integration, not a complete `computeMemberships` port with
smoothing, atlas-prior energy construction, or multi-voxel distance maps.
Regenerate with
`scripts/generate_java_lesion_toads_membership_integration_reference.sh`.
