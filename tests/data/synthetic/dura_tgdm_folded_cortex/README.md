# Synthetic folded-cortex Dura TGDM reference

- **Dimensions:** 25 × 25 × 25 voxels in Java `[x][y][z]` order.
- **Spacing and affine:** isotropic 1 mm; identity RAS affine for geometric
  measurements.
- **Fields:** an analytic radial cortex with angular folds, a nested inner
  reference level set, and a smooth gray-matter intensity field. Values and
  full evolution checkpoints are in `java_reference.json`.
- **Provenance:** deterministic synthetic data generated by
  `DuraTGDMFullEvolutionReferenceHarness.java`; no subject images are used.
- **Reference code:** selected VandyCRUISE `GenericTGDM`,
  `DynamicPressureTGDM`, and `DynamicPressureCortexProfile`; the harness uses
  the original JIST `DistanceField.class` (SHA-256
  `92294be2db74351446c3e5898fc35b58497f89ccb38772d4d565885f3f0c35b7`). A
  headless compatibility shim avoids loading MIPAV UI classes; JIST's actual
  image and distance-field classes are used.
- **Regeneration:**

  ```sh
  JIST_TEST_JAR=/path/to/JIST-Test.jar JIST_LIB_DIR=/path/to/JIST/lib \
    DURA_TGDM_OUTPUT=tests/data/synthetic/dura_tgdm_folded_cortex/java_reference.json \
    DURA_TGDM_NX=25 DURA_TGDM_NY=25 DURA_TGDM_NZ=25 \
    DURA_TGDM_FOLDED=true \
    scripts/generate_java_dura_original_jist_reference.sh
  ```

The Java profile stops its first pass after 27 updates when the landmine
reinitialization condition is met, then completes four 30-step passes. The
Python run matches the 147 total updates and one restart. Against the Java
final level set, current Python metrics are Dice 0.997923, symmetric mean
surface distance 0.005180 mm, and Hausdorff distance 0.328474 mm. These pass
the project thresholds. Four voxel signs differ; pass arrays show small
intermediate distance-field deviations, so this is metric-level validation,
not exact voxelwise equivalence.
