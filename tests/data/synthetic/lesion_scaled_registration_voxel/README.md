# Scaled LesionTOADS registration voxel reference

`java_reference.json` contains outputs from
`tests/java_reference/LesionScaledRegistrationVoxelReferenceHarness.java`.
The fixture is generated by
`scripts/generate_java_lesion_scaled_registration_voxel_reference.sh` using the
selected upstream `ParametricTransform`, `RotationMatrix`, and
`ImageFunctions` Java sources.

The harness exercises one voxel at each registration pyramid scale (2, 4, and
8), with both an in-bounds template sample and a translated out-of-bounds
sample. It records the scaled image-to-template coordinates, interpolated
class priors and gradients, rigid coordinate Jacobian, and that voxel's
registration cost, norm, gradient, and diagonal Hessian contributions. The
synthetic class maps have deterministic affine/bilinear intensity patterns;
class 0 is excluded from the registration prior calculation.

This is a selected **formula-level Java reference**, not a complete
LesionToadAtlas run. It does not validate volume traversal or reduction order,
registration optimization, pyramid construction, convergence, or final
transforms. The test compares the Python voxel composition directly with these
Java outputs and should be interpreted only within that scope.
