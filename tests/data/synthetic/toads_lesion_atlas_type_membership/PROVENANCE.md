The Java harness parses the descriptor in source order, runs the selected
class-energy and lesion-centroid branches, then follows the x/y/z and class
membership update/normalization order. It records 16 cases for all on/off
combinations of field, PSF bias, smoothing, and prior. Rebuild input volumes
with `scripts/generate_toads_lesion_atlas_type_fixture.py`, regenerate the
reference with the shell command above, and run
`pytest -q tests/test_toads_lesion_atlas_type_membership.py` for bitwise
comparison.

This is a fixed-statistics exact-membership slice. It does not implement
atlas loading, template resampling, centroid/variance/field estimation,
approximate membership mode, topology/growth, registration, or outer-loop
control.
