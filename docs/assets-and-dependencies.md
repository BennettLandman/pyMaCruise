## Distribution and repository policy

- Keep human imaging data out of Git. Use only synthetic data in `tests/data/synthetic/` unless the owner explicitly authorizes a shareable data release.
- Do not copy the hundreds-of-megabytes atlas trees or OASIS-named image files into PyMaCRUISE while their applicable data/code terms are undocumented. The GitHub repo is private, but private visibility alone does not establish redistribution rights.
- MIPAV and JIST have license/notice files in their source trees; VandyCRUISE, toads-cruise, and the MaCRUISE folder had no top-level license file in this inventory. Check individual source-file headers and obtain project-owner guidance before shipping derived code or bundled atlases.
- The finished Python port should depend on documented Python packages and configured external atlas files where needed; it should not require MATLAB, MIPAV, JIST, or a JVM at runtime.

All active Java adapter source needed for the base MaCRUISE workflow was located across VandyCRUISE and `toads-cruise/src`; the plus lesion atlas list/data are also supplied.
