# P18an: optimized-tissue class standard deviations

## Scope

This slice implements the optimized CSF/GM/WM branch of
`MultipleToadSegmentation.computeExactVariances`. For each modality and
class, it selects voxels whose categorical segmentation equals that class,
accumulates membership-squared stabilized residual-square weights over the
full grid, then returns the square root of the weighted mean squared
residual. The optional multiplicative field is applied before subtracting
the class centroid. A class with no assigned voxels returns zero, matching
the source.

All membership channels provided to this function are treated as optimized
tissue classes. This is a prerequisite for centroid similarity weighting,
not that weighting itself or a complete TOADS update. OBJECT, OUTLIER, and
LESION branches remain outside this slice.

## Synthetic reference

The committed categorical segmentation is generated by
`(x + 2*y + z) % 3` on a 7×6×5 grid and stored as RAS 1 mm `.nii.gz`. The
three-modality image and field volumes and the first three membership
channels are reused from existing synthetic fixtures. Three initial
centroids are fixed in the Java formula harness. The selected source SHA-256
is `63e135f36dd9117a4f6dda2ec78990230e5e44ad91234ce3745d20e5976cd884`.

Regenerate the assignment image with
`scripts/generate_toads_optimized_class_variance_fixture.py` and the Java
formula outputs with
`scripts/generate_java_toads_optimized_class_variance_reference.sh`.

## Validation

`tests/test_toads_optimized_class_variance.py` compares all nine standard
deviations exactly as float32 for field-disabled and field-enabled modes.
It also checks that a class with no assigned voxels returns zero and that
invalid dimensions and non-integer assignment labels reject. The focused
module passes **6 tests**.

The complete configured suite passes **332 tests in 60.47 seconds** on
implementation commit
`46408971a49138fcd8d76786f8c386f5fcefba44`; see
[`full-pytest-2026-09-28.md`](full-pytest-2026-09-28.md). These results
establish matching formula outputs for the tested synthetic optimized-tissue
