# P37 Stage-wise Equivalence Evidence Inventory — 2026-09-30

## Status

This is an inventory of existing synthetic Java/source comparison evidence, not a P37 pass. P37 remains **Not started** in [`plan.md`](../../plan.md#L219). The criteria are stage-wise comparison to MATLAB/JIST or a trusted reference, deterministic label equality where expected, agreed P08 metrics for numerical/final products, transform-direction and mesh-coordinate checks, and explicit decisions for deviations. This report did not run tests or recompute metrics; figures below are transcribed from the cited reports and machine-readable result files.

The owner-approved thresholds in [`validation-tolerances.md`](../validation-tolerances.md) are:

- **Each required segmentation label/region:** Dice at least 0.97.
- **Surface distance:** symmetric Hausdorff at most 1 mm RAS+.
- **Surface position:** symmetric mean nearest-surface distance at most 0.01 mm RAS+, with mesh vertices as deterministic samples and exact closest points on the opposing triangles.

For deterministic label maps, exact voxel equality on a fixture implies Dice 1 for that compared map. It does not establish an untested class/region, larger geometry, end-stage output, or complete workflow.

## Metrics absent or not yet decision-ready

1. **No end-to-end base or plus comparison.** P34 is Blocked, P39 is Started, and P40/P41 are not complete. The current evidence therefore cannot supply a per-required-label Dice table and surface metrics for all promised base/plus products. See the status summaries in [`plan.md`](../../plan.md#L17), P34/P39–P41 in [`plan.md`](../../plan.md#L216), and P39's status overview in [`plan.md`](../../plan.md#L26).
2. **Most TOADS/LesionTOADS rows are component contracts.** Their test oracles often compare exact maps, formula outputs, queues, or supplied-input compositions. They do not compute P08 Dice and surface metrics for final anatomical output labels. Explicitly retain this distinction even where the numerical comparison is exact.
3. **The larger folded TGDM Java match is only partial.** P29's selected 25³ Java comparison passes all three reported thresholds; the 41³ folded Java comparison is not present. The separate 25³ folded Dura TGDM P18cj result does pass, but covers that one Dura evolution slice and its final mask.
4. **Surface extraction has a passing sampled metric but a material mesh substitution.** The P57 fixture's measured vertex-to-triangle values are tiny, but face connectivity differs materially. The sample maximum is not a continuous Hausdorff certificate, and the observed thickness delta has no P08-wide threshold. Keep this risk open under P37 pending broader level sets and downstream mesh-dependent comparisons.
5. **Scalar-volume thresholds remain stage-specific.** P08 defines no universal scalar MAE/RMSE/max-error bound. ACE/TGDM/TGDM-distance and lesion energy deviations must keep their source-specific evidence and acceptance decisions, rather than being silently absorbed into Dice/surface thresholds.
6. **Transform and physical-grid substitutions need explicit P37 disposition.** ANTsPy registration substitutes for Aladin/NiftyReg; check direction, landmarks, interpolation, target grid, and all surfaces/meshes transferred through the transforms. P33/P38 evidence validates declared synthetic contracts, not optimizer identity with those unavailable tools.
7. **Evidence snapshot is mixed in freshness.** The latest plan-level full-suite figure is 810 passed on `d84f2039fe45e6c90cd040a559cc09029a379b7a`, and `plan.md` notes newer P18/P39 code is not included. Re-run the complete suite after those changes are integrated before attributing current pass status to the inventory.

## P37 closeout evidence still required

- For every complete synthetic workflow stage, list the reference and Python source revisions, input grid/affine, RAS conversion, parameters, and exact source/algorithm path.
- For final labels, report Dice **per required label/region**; retain exact voxel equality for deterministic operations where expected.
- For every required surface pair, report symmetric Hausdorff and symmetric mean nearest-surface distance in RAS+ mm, including both directed values, sampling definition, and compared grids. Identify sampled estimates separately from a continuous geometric bound.
- For any continuous scalar outputs, define a stage-specific numerical limit before calling that stage equivalent.
- Record every mismatch, source-faithful bug behavior, unsupported branch, and library substitution with an explicit accept/fix decision. In particular, carry the JIST/Lewiner face-connectivity and thickness effect into P37.
- After P35/P36 evidence is current and full base/plus synthetic workflows exist, regenerate a single traceable P37 metrics report tied to the exact tested commit. Do not use real images to fill a synthetic source-comparison gap.
