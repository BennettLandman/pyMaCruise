# Human BASE TGDM comparison using the saved Dura mask level set — 2026-10-17

## Scope and evidence type

This is a **real-human, held-fixed selected-source TGDM stage comparison** on case 100260's regenerated BASE attempt-02 crop. It is not a fresh original MATLAB/MIPAV full workflow run. Initial membership, WM/GM, ACE, skeleton, and GVF are held to the saved Python stage inputs; Java and Python receive the same cropped Dura `brain_mask_level_set.nii.gz`, including its signed magnitudes (−5 to +5). The Dura level set was generated by PyMaCRUISE, so this validates the TGDM stage's raw mask-bound handoff, not the original Dura implementation or complete BASE workflow.

Input and selected Java source hashes, affine, crop provenance, memory, and all voxel/surface metrics are in the [machine-readable report](in-vivo-base-tgdm-dura-mask-levelset-java-parity-2026-10-17.json). ## Code change

The array and image TGDM APIs now distinguish a binary `brain_mask` from a signed `brain_mask_level_set`. Binary masks retain the established unit inside-negative conversion. An explicitly supplied signed level set preserves its values; that is necessary because the selected Java TGDM clamp uses the bound's values as well as its sign. The standalone TGDM command and BASE CRUISE core expose this input. Full BASE workflow passes the Dura stage's level-set output to TGDM; the resume-from-TOADS path passes its available T1-grid user mask.

Focused tests on implementation commit `8438185d49fcb8ebd49626dc249d763b89a02ffc` passed **43 tests** across TGDM, BASE core, restartable BASE, and BASE resume integration. The full suite on that same commit passed **1,683 tests, skipped 4, and had 0 failures**, with 30 expected RAS warnings in 1,000.52 seconds and peak sampled RSS of 9.435 GB under a 16 GB watchdog.
