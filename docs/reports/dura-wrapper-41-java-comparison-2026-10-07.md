# Selected Dura wrapper sequence on 41³ synthetic cases

## Scope

The selected VandyCRUISE `MedicAlgorithmRemoveDura09.execute()` sequence was
compared against Python on scaled 41×41×41 synthetic attached-dura and no-dura
cases. The Java test harness calls the selected `AlgorithmTopologyCorrection`,
`DistanceFieldyh` adapter (whose source header says it is identical to the
omitted `DistanceField`), and selected `DynamicPressureTGDM` implementation.
It does not launch the full MIPAV/JIST application. All fixture images are
committed as RAS `.nii.gz` files with a SHA-256 manifest in
[`tests/data/synthetic/dura_attached_no_dura_41`](../../tests/data/synthetic/dura_attached_no_dura_41).
No human data was used.

The wrapper sequence includes WM topology correction, the WM+GM float32 union,
GM topology correction, the capped inner/outer distance fields, five TGDM
passes, brain-mask thresholding, and masking of the returned T1/WM/GM images.
Settings are membership 0.4, mask translation 2, level-set translation 0, and
five outer TGDM passes. Java completed 150 internal updates for each case.

## Results

Both cases match exactly for both topology-corrected fields, the final binary
brain mask, stripped T1, and corrected WM/GM outputs. The final brain-mask
level-set differs by at most `0.000304` intensity units and retains the same
sign mask. The inner signed-distance field differs by at most `0.000699`; the
outer field differs by at most `0.001412`. Both retain the same sign masks.

All five TGDM pass fields have identical signs in both cases. For the attached
dura case, the maximum absolute differences by pass are `0.01381`,
`0.000523`, `0.000315`, `0.000297`, and `0.000304`; the first-pass mean error
is `0.000138`. The no-dura pass differences are effectively the same. Final
level-set Dice is **1.0** in both cases. The mesh results are:

| Case | Symmetric mean nearest-surface distance | Hausdorff distance | Vertices |
|---|---:|---:|---:|
| Attached dura | `0.0000619 mm` | `0.000293 mm` | 3,030 each |
| No dura | `0.0000619 mm` | `0.000292 mm` | 3,030 each |

These meet Dice ≥0.97, symmetric mean distance ≤0.01 mm, and Hausdorff ≤1 mm.
The source-level differences in distance and early TGDM fields are recorded
rather than hidden inside those final geometry metrics.

## Reproduction

From the repository root:

```sh
DURA_WRAPPER_NX=41 DURA_WRAPPER_NY=41 DURA_WRAPPER_NZ=41 \
DURA_WRAPPER_OUTPUT=build/java-reference/dura-attached-no-dura-41/reference.json \
scripts/generate_java_dura_wrapper_reference.sh

./.venv/bin/python scripts/convert_dura_wrapper_java_json.py \
  build/java-reference/dura-attached-no-dura-41/reference.json

./.venv/bin/python scripts/run_with_rss_watchdog.py \
  --limit-gb 8 --interval-seconds 0.1 --report-interval-seconds 30 -- \
  ./.venv/bin/pytest -q \
  tests/test_dura_wrapper_41.py \
  tests/test_dura_attached_no_dura_java_reference.py
```

The Java generator was rerun independently; its JSON output SHA-256 was
`cf5fab7526d7aa8921fe149b7f7490ed0c007fed7432aa558bbd35e6226c5e91`, identical
to the captured reference. Focused tests passed **2 tests in 23.41 s**, sampled
peak RSS **0.172 GB** under the 8 GB watchdog. No full repository suite was run
for this stage.

## Boundary

This closes the selected synthetic Dura wrapper-sequence comparison for these
two scaled cases. It does not establish parity for the Dura inputs generated by
the brain-resolution base TOADS run, the complete base workflow, or human MRI.
The selected Python working space remains native T1 RAS; historical
BET/SPECTRE preprocessing remains an intentional workflow deviation.
