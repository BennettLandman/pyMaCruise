# N4 bias correction paper-to-code notes

## Published method

Tustison NJ, Avants BB, Cook PA, Zheng Y, Egan A, Yushkevich PA, Gee JC.
“N4ITK: Improved N3 Bias Correction.” *IEEE Transactions on Medical Imaging*.
2010;29(6):1310–1320. DOI
[10.1109/TMI.2010.2046908](https://doi.org/10.1109/TMI.2010.2046908);
[PubMed](https://pubmed.ncbi.nlm.nih.gov/20378467/).

The paper describes N4's iterative bias-field estimation, including a
B-spline model and sharpened intensity-histogram estimation. PyMaCRUISE does
not independently implement those numerical steps: it calls ANTsPy, which
delegates to the ANTs N4 implementation. The citation explains the algorithm
being used, not a claim that the Python wrapper reimplements or independently
validates the paper's method.

## Code crosswalk

| Python code | Relationship to the method | Source-specific boundary |
| --- | --- | --- |
| [`n4.py`](../../src/pymacruise/n4.py): `_nib_to_ants`, `n4_bias_correct` | Converts the normalized NIfTI image to ANTs' image representation and calls `ants.n4_bias_field_correction`; the N4 estimation is external. The corrected array is returned with the original normalized RAS grid and metadata. | This is an adapter, not a local implementation of the paper's estimation procedure. |
| [`n4.py`](../../src/pymacruise/n4.py): `N4Config` and call arguments | Maps the selected MATLAB V3 wrapper's bare `N4BiasFieldCorrection -i input -o output` invocation to explicit ANTsPy settings: no mask, intensity rescaling off, shrink factor 4, four levels of 50 iterations, tolerance 0.0, and a 1×1×1 spline mesh. | These values represent wrapper/ANTs CLI defaults. They are not parameter values prescribed by Tustison et al. ANTsPy's documented default tolerance is 1e-7, so the adapter explicitly sets the CLI value 0.0 for this source profile. See [ANTsPy N4 API](https://antspy.readthedocs.io/en/latest/core.html) and [ANTs N4 command-line options](https://github.com/ANTsX/ANTs/wiki/N4BiasFieldCorrection). |
| [`n4.py`](../../src/pymacruise/n4.py): RAS/LPS conversion and output reconstruction | Handles coordinate conventions at the library boundary and preserves the normalized input grid for output. This is interoperability behavior around N4, not an algorithmic contribution of the paper. | The callable accepts finite, non-negative 3D NIfTI scalar images and rejects empty-positive inputs; these are wrapper preconditions. |

## Validation scope

P19's synthetic multiplicative-bias checks assess bias reduction, repeatability,
and preservation of the RAS affine/grid; see the P19 entry in
[`plan.md`](../../plan.md) and the recorded full-suite evidence. Those checks
validate this adapter on synthetic data. They do not establish equivalence to
the MATLAB wrapper on clinical images or independently validate ANTs' N4
implementation against the published experiments.
